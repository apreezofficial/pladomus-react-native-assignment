# Lottie Animation Assets

This folder contains Lottie animation JSON files for weather conditions.

## Usage

Download Lottie animations from:
- https://lottiefiles.com/featured
- https://lottiefiles.com/weather

Recommended animations:
- `sunny.json` - Sun animation for clear weather
- `cloudy.json` - Cloud animation for overcast
- `rainy.json` - Rain animation for precipitation  
- `snowy.json` - Snow animation for winter weather
- `stormy.json` - Lightning/storm animation
- `loading.json` - Loading spinner
- `wind.json` - Wind animation for weather details

## Free Lottie Weather Animations

Search for these on LottieFiles:
- "weather sunny" by various authors
- "rain animation" by various authors
- "cloud animation" by various authors
- "loading spinner" by various authors
